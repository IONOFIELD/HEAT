# Henry's Territory

Field sales map for Henry's dispensary accounts across the Bay Area.

- Live app: https://ionofield.github.io/HEAT/
- Map: MapLibre GL + OpenFreeMap vector tiles, © OpenStreetMap contributors
- Store search: Photon (komoot) · Nearby dispensaries: Overpass API (OpenStreetMap)
- Zones: Bay Area county boundaries
- Data is stored on each device (localStorage), with export/import backup.
